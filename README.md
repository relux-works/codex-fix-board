# codex-fix-board

Task board for the Codex goal-mode token-burn patch series developed in
[relux-works/codex](https://github.com/relux-works/codex) (branch `relux/main`).

- Background: [Why Codex burns a weekly limit in a day](https://relux.works/en/blog/codex-goal-token-burn/).
- Board format: [task-board](https://github.com/relux-works/skill-project-management) (`.task-board/`).
- Accepted plan: `TASK-260929-1srn2y` outcome `TASK-260929-1srn2y_goal-token-burn-final-plan.md`.
- Stories map one-to-one to planned pull requests; each Story lands on `relux/main` of the fork and
  its board state is recorded here by `task-board worktree complete`.

The board is kept out of the code repository's git history on purpose.
