AC3 Code-mode leaves are counted once: one nested leaf that applies a file change yields exactly one observation, and the wrapper adds none (test with a narrowing mutant that double-counts or counts the wrapper). AC4 No model-writable bypass: no tool argument, plan text or message content can set the observation (test). AC5 The existing activity booleans and the three-fully-empty-continuations blocker (ext/goal/src/accounting.rs:216-229) behave exactly as before (regression tests stay green; one test asserts the blocker still fires first). AC6 The observation is transient: it is not persisted to rollout or history, and resume starts with no carried observation (test). AC7 Arbitrary shell side effects are a stated bound: the results file must say that they are unknown, so pacing may stay conservative and completion is never inferred from them. AC8 Every gate (each reset source and each non-reset) ships a narrowing mutant with a named killer test, per the checklist.
