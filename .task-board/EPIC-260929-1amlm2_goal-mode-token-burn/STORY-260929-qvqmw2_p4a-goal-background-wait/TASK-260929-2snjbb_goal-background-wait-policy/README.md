Invalidate tickets on steering, turn start, goal mutation, clear, stop and release; resume discards stale waits. Releasing a mis-armed subscription allows paced continuation without a kill. A failed snapshot read is not 'no pending work'. Use the safe behavior (no automatic continuation past the gate) and state it. Use deterministic or fake time, never real sleeps.
